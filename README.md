# SMASH ROOM v0.15

[Играть](https://evidday.github.io/paleo-microhabitat/?v=15) или открыть src/index.html без сервера и установки.

Одна непрерывная поляна: два питомника у краёв общей гекс-карты. Кнопки двигают камеру, карта и грибы остаются в одном мире; перед боем отряды выходят в центр и возвращаются домой.

Свой питомник: выпадают карты, два одинаковых гриба одного тира объединяются в следующего, до Т3. Расставьте постоянный отряд в два ряда и нажмите «Готов». Каждый раунд проходит настоящий 3D-автобой; цель — пять побед.

Общие гексы производят воду, перегной и споры для армии. Один рост за раунд стоит 1 воду + 1 перегной. Карты бойцов имеют разные цены; обмен припасов с запасом — 3:1. Купленные грибы возвращаются после боя, нокаут их не удаляет. Продажа возвращает только 1 перегной, карта не возвращается.

На телефоне: карта → пустое место → нижняя кнопка найма. Боец → объединить, накормить или переставить; перетаскивать не требуется. Рука прокручивается горизонтально. Поддерживаются бот (два стиля) и поочерёдная игра вдвоём на одном устройстве.

- Щит: много HP, мало урона. Отдельного поглощения урона пока нет.
- Задира: сильный ближний удар.
- Плевун: дальняя атака, мало здоровья.
- Корм: 1 вода + 1 перегной → +2 HP/+1 урон на один бой.
- Партия заканчивается при пятой победе; после 20 раундов сравниваются победы, равенство — ничья.

## Проверки

- node tests/run-nursery.cjs — экономика, карты/стак, расстановка, реальные исходы, конец/replay и 120 партий.
- node tests/simulate-nursery.cjs — 240 сравнительных игр эвристик, результат tests/nursery-simulation-results.json.
- tests/nursery-flow-check.cjs — полный матч кнопками/касаниями при 390/900/1440, реальный планировщик бота и fallback без WebGL. Playwright/Edge, адрес задаётся NURSERY_TEST_URL.
- tests/index.html — браузерные проверки движка и питомника, запускаются через file:///.
- Прежние run-colony и run-garden* продолжают проверять сохранённые режимы; они не заменяют проверки v13.

Баланс не доказан: ранняя армия сильнее экономического бота в текущих пробах. Проверка мобильной вёрстки и touch — не замер производительности на физическом телефоне. Случайные события, прямые переговоры и физический ragdoll не добавлены.
