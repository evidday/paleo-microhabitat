# SMASH ROOM v0.18

[Играть](https://evidday.github.io/paleo-microhabitat/?v=18) или открыть src/index.html.

**Нажми свою грибницу → «Посадить» или «Разрастись» → в бой.**

Грибница — твоя база и постоянный отряд. Сначала видно только поле и подсказку Хихикорня. Пять предложений, ресурсы, рост и дополнительные действия появляются по твоему запросу, а не все сразу. В наборе пять предложений: покупай несколько за припасы, одинаковые сами складываются до ★★★. Первые 6 мест сражаются, 3 — резерв. Бойцы смотрят на реальную цель, прежний принудительный поворот к камере убран. Бой каждый раунд на общей поляне; пять побед — конец партии. Погибший пропускает один бой на регенерации и возвращается с косметической мутацией. Ручного воскрешения нет.

Рост от любой своей ветки: не обязательно вперёд. Один гекс за раунд стоит 1 воду + 1 перегной и даёт доход со следующего утра. Руины сразу дают редкого бойца, источник — двойной доход, лавка — обмен2:1. Типы связанной сети усиливают здоровье/лечение/дальность один раз; повторные гексы дают дополнительный доход. Всего12 видов, четыре царства, альбом на устройстве. Корм/перестановки/торг доступны дополнительно.

Друг по ссылке: выбрать комнату → создать → отправить ссылку → друг входит → хозяин начинает. Есть согласуемый обмен припасами. Хозяин держит вкладку открытой. Некоторые сети блокируют P2P; бот и hotseat доступны без комнаты.

## Проверки
- node tests/run-nursery.cjs — 11 групп: пять предложений/несколько покупок/цены/стак, обновления, боковые ветки, немедленная находка и полный питомник, сеть, каждый бой, смерть/восстановление, торг, конец/replay и240 полных матчей.
- node tests/simulate-nursery.cjs —240 сравнительных матчей двух эвристик, nursery-v18-comparison.json.
- node tests/nursery-balance.cjs —500 зеркальных и500 разных составов, покупочные ID, контрпримеры и расстановка.
- node tests/nursery-v18-flow.cjs —полные партии реальными кнопками при390/900/1440, касания, покупки и земля за один раунд. NURSERY_TEST_URL задаёт сайт, NURSERY_TEST_WIDTH один размер.
- node tests/nursery-v18-extra.cjs —tests/index.html, альбом, VS/3D, fallback/reduced-motion.
- node tests/nursery-room18.cjs —два независимых WebRTC-клиента: лобби/торг/полный матч/обрыв/возврат. SMASH_URL задаёт сайт.

Баланс эвристик не равен человеческому: в v18 экономика с находками сильнее чистого раннего найма. Физический телефон и разные провайдеры ещё требуют плейтеста. Подробности: PLAYTEST.md; правила: DESIGN.md; публикация: DEPLOYMENT.md.
