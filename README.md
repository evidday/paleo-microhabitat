# SMASH ROOM v0.17

[Играть](https://evidday.github.io/paleo-microhabitat/?v=17) или открыть src/index.html.

Одно развитие за ход: новый гриб **или** продвижение армии. Земля даёт припасы, руины открывают редкие виды, три связанных участка открывают ★★★. Бой начинается при встрече фронтов, а не каждый раунд; пять побед заканчивают партию. Проигравший отступает, сохраняя бойцов для нового плана.

Своя грибница открывает три предложения, расстановку, корм и торг. Дубликаты одного вида/тира автоматически складываются. Шесть мест воюют, три — резерв. Всего 12 видов, четыре царства с реальными особенностями, альбом коллекции на устройстве. Карту и ориентиры генерирует seed, ресурсы новых земель выбирает игрок. Хихикорень коротко объясняет текущий выбор.

Для друга на другом устройстве: «Друг по ссылке · комната» → создать → отправить ссылку → друг входит → хозяин начинает. Есть согласуемый обмен припасами. Хозяин держит вкладку открытой; при обрыве можно вернуться по коду. Интернет нужен комнате, некоторые сети блокируют P2P. Бот и друг на одном экране остаются доступны без комнаты.

## Проверка
- node tests/run-nursery.cjs — 12 групп: карты, одно развитие, фронты, победа/отступление, снабжение, расы/типы, резерв, ★★★, руины, обмен, конец и replay; 240 полных матчей.
- node tests/nursery-balance.cjs — 500 зеркальных и 500 разных составов без преимущества покупочных ID, контрпримеры и влияние расстановки.
- node tests/simulate-nursery.cjs — 240 сравнительных матчей двух стилей, данные nursery-v17-comparison.json.
- node tests/nursery-v17-flow.cjs — полные партии кнопками при 390/900/1440, touch, настоящий одиночный бот, fallback/reduced-motion. NURSERY_TEST_URL задаёт публичную страницу.
- node tests/nursery-room17.cjs — настоящие независимые WebRTC-клиенты: лобби, торговля, полный синхронный матч, запрет чужого хода, обрыв/возврат. SMASH_URL задаёт публичную страницу.
- tests/index.html — браузерные проверки legacy/v15/v16/v17.

Автоматические проверки не доказывают удовольствие/человеческий баланс. См. PLAYTEST.md: агрессивная стратегия ещё сильнее в сравнении эвристик; физический телефон и сети разных провайдеров требуют отдельного плейтеста.
