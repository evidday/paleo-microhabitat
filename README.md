# SMASH ROOM v0.16

[Играть](https://evidday.github.io/paleo-microhabitat/?v=16.1) или открыть src/index.html без установки и сервера.

Основной экран — поле. Коснитесь своей 🍄＋: появятся три предложения и места расстановки. Один выбор за раунд, цена показана на бойце. Дубликаты складываются сами, цепочкой до ★★★; отдельной кнопки объединения нет. Можно переставлять бойцов, кормить, менять предложения и обменивать припасы.

Шесть типов: 🛡 броня, 🥊 сильный удар, 💨 дальний выстрел, 💚 лечение, ⚡ прыжок к дальнему врагу, 💣 урон группе. Роль, тир, расстановка и прикрытие имеют значение. Порядок покупки не является боевым параметром. Первые предложения одинаковы для обоих, далее появляются разные наборы; фракции смещают предложения к любимому типажу, без скрытых бонусов HP/урона.

Форма карты видна заранее. Дальние владения соперника скрыты до подхода сети. На соседнем ＋ выберите воду, перегной или споры за 1💧 1🌿. Со следующего утра гекс даст единицу выбранного ресурса. Свой гекс можно перестроить за 1💧 2🌿 1✦ вместо роста. Грибницы и бойцы — на одной поляне, бой происходит в её центре. Победа за пять боёв; защитный предел 20 раундов.

## Проверка
- node tests/run-nursery.cjs — автостак/полный питомник, цены, три предложения, карта/разведка/перестройка, шесть способностей, конец/replay, 160 партий.
- node tests/nursery-balance.cjs — 500 зеркальных боёв и смена покупочных ID, пять контрпар, влияние расстановки. Данные tests/nursery-v16-balance-evidence.json.
- node tests/simulate-nursery.cjs — 240 сравнительных игр двух эвристик, tests/nursery-v16-simulation-results.json.
- tests/nursery-v16-flow.cjs — полные матчи реальными кнопками/касаниями при 390/900/1440, одиночный бот, fallback/reduced-motion. NURSERY_TEST_URL задаёт публичный адрес.
- tests/nursery-v16-extra.cjs — реальная платная перестройка и отображение всех шести ролей с лечением/прыжками/взрывами.
- tests/index.html — проверки legacy, v15 и v16 через file:///.

Автоматические проверки не доказывают человеческий баланс или удовольствие. Сравнение двух ботов не измеряет винрейт реальных игроков. Производительность физического телефона ещё не измерена.
